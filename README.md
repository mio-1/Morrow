# Morrow · 个人生活工具箱

Android App，包含小青账资产同步、多个长期目标、可配置资产类别与金额/比例目标，以及按日期分组的待办与待办库。底部为「资产 / 待办 / 设置」；设置按页面管理显示模块。

## 安装与开始使用

从 [GitHub Releases](https://github.com/mio-1/Morrow/releases/latest) 下载最新的 `Morrow-*.apk`；本地构建则会生成在 `dist/`。Android 8.0 及以上，需可正常运行现代 JavaScript 的系统 WebView。没有服务端部署步骤。

1. 「设置 → 连接管理 → 小青账」中连接账户，在 App 内输入小青账手机号与密码。资产页的“连接账户”也会打开小青账连接详情。不会使用或打包电脑上已有的会话。
2. 在资产页进入账户列表，把同步账户归到股票、债券、现金等类别；也可查看资产趋势。
3. 在资产配置中设置各类资产的目标比例或固定金额。类别支持新增、改名和颜色设置。
4. 在长期目标中创建多个目标：名称、目标金额、截止日期，以及全部资产或某个资产类别的口径。
5. 「设置 → 资产页面」可开关概览、账户、趋势、长期目标、资产配置；「设置 → 待办页面」可控制是否显示已完成事项。待办页按日期展示未完成事项与完成记录，可设置低、中、高优先级；每条待办显示剩余天数，颜色随日期接近及优先级平滑变化。待办库只放未完成且尚未安排日期的事项。
6. 「设置 → 检查更新」会读取 [Morrow GitHub Releases](https://github.com/mio-1/Morrow/releases) 的最新公开版本；有新版本时可打开发布页。首次发布 Release 前会显示“暂无已发布版本”。

手机桌面名称为 Morrow；Android 包名暂保持 `com.shiji.life`，以便覆盖安装旧版。

这是 Android APK，不是鸿蒙 HAP；鸿蒙 NEXT 需通过支持该 APK 的安卓兼容环境运行。兼容环境下的行为尚需设备端确认。

源码仓库不包含签名私钥或 APK。构建更新包时设置 `MORROW_SIGNING_KEY` 为原有私钥路径，再运行 `npm run build:android`；使用不同私钥签名的 APK 无法直接覆盖已安装版本。首次公开版本号为 `0.1.0`，Android `versionCode` 为 13，能够覆盖此前 `0.7.5` 的内部构建（`versionCode` 12）。检查更新以 APK 制品名中的 `versionCode` 判断新旧。

## GitHub 自动构建与发布

推送到 `master` 或 `main` 会运行测试并生成 Actions APK 制品；推送对应版本的 `v*` 标签后，同一工作流会把 APK、SHA256 和构建信息发布到 GitHub Releases。仓库需配置 `MORROW_KEYSTORE_BASE64`、`MORROW_KEYSTORE_PASSWORD`、`MORROW_KEY_ALIAS`、`MORROW_KEY_PASSWORD` 四个 Actions Secrets。私钥内容不进入 Git；`MORROW_KEYSTORE_BASE64` 是原有签名文件的 Base64 内容。标签版本必须与 AndroidManifest 的 `versionName` 一致。

## 已实现

- 多目标：增、改、删；独立金额和日期；支持按全部资产或单个类别计算。
- 进度指标：当前金额、完成比例、剩余金额、剩余天数、每月还需积累金额、相对基准线性计划的差距。首次取得资产时设基准；类别口径改变时重设相关类别的基准，不修改截止日期。
- 达成预测：最近 30 天内至少跨越 7 天的快照，并存在正向资产变化时才估算。没有历史记录时明确显示“数据积累中”。
- 资产配置：比例目标总和校验为 100%；固定金额目标；当前占比、目标金额、差额、百分点偏差。
- 自定义股票、债券、现金之外的资产类别；类别删除时将关联账户与目标份额归入“其他”。有长期目标引用的类别不能直接删除。
- 实际账户的配置目标初始为空，金额和比例都由你设置。
- 小青账只读同步；启动时超过 15 分钟未同步会尝试刷新，也可手动同步；失败时保留上次数据；令牌过期提示重新登录。
- 连接管理：外部服务在设置中集中列出，当前支持小青账；各连接独立展示状态和操作，方便以后加入其他服务。
- 本地手动资产账户：新增、编辑、删除，与同步账户分开管理。
- 本地每日资产快照和按真实日期间距绘制的趋势。
- 待办：按待完成日期排序分组，待办库收纳尚未安排日期的事项；方框一键完成或恢复，支持修改日期、内容和删除。
- 页面配置：资产页可选概览、账户、趋势、长期目标和资产配置；待办页可选已完成事项和截止日期。关闭显示项不删数据。
- 详情配置：长期目标可选已完成目标、月度所需金额和预计达成日期；资产配置可选占比、目标差距和进度条。

## 资产与目标口径

依据用户提供的“招商银行信用卡不计入、储蓄卡计入”示例与接口实际数据核对：`reckonIn: true` 表示“不计入”，排除这些账户；`false` 表示计入。`display` 和 `status` 不能用作“不计入”的替代条件，隐藏账户不会被自动排除。

人民币余额按接口原符号累计（负数已包含负债，不再二次扣除）。内部金额累计用“分”四舍五入，避免普通浮点求和的分钱误差。外币暂不折算，会显示未纳入的账户数量，不使用虚构汇率。

多个目标是按所选资产分别计算的里程碑，不是独立资金信封，不能把多个目标的已攒金额相加。固定金额的“股票目标”可以在长期目标中选择“只看股票”并设置截止日期；比例配置基于当前计入总资产，而不是未来某个总金额。

资产变化包含估值涨跌和账户变化，不等于现金流净存入；本月指标需存在月初或前一日快照，不根据当前余额补造过去数据。类别归属改变后，不用旧口径的历史快照推算该类别增长速度。

## 数据与凭证

- APK 内没有预置手机号、密码、个人资产、电脑端令牌或测试账户。
- 密码仅用于向固定 HTTPS 登录端点发送一次登录请求，不保存；其 Base64 处理沿用官网协议，传输保护依靠 HTTPS。
- AndroidKeyStore 的 AES-GCM 密钥加密会话令牌，密钥不写入代码或偏好设置。
- 账户数据、目标、类别、快照和待办保存在 Android 应用私有目录；状态文件使用 AtomicFile 更新。关闭 Android 自动备份。
- 断开连接会删除令牌、同步资产和快照，保留目标、手动账户、类别和待办。卸载会删除本地数据。
- 只加载 APK 自带的 HTML/JS；WebView 禁止外部网页、文件访问、混合内容及网页直接联网。网络操作由固定域名的原生桥处理。
- App 只调用登录及资产读取，不开放账单创建、删除、修改或验证码发送。
- 小青账接口不是官方公开 SDK；目前基于用户提供的 APK、官网代码和本人登录后的只读调用验证。服务调整时可能需要更新或重新登录。

## 结构与扩展

```text
app/src/main/java/com/shiji/life/MainActivity.java   原生壳、网络、密钥库、原子持久化
app/src/main/assets/core.js                        模型、迁移、金额与进度计算
app/src/main/assets/app.js                         模块页面、交互、原生桥
app/src/main/assets/style.css                      离线移动界面基础样式
app/src/main/assets/modern.css                     蓝白视觉样式
tests/core.test.cjs                                业务边界测试
scripts/browser-test.cjs                           完整界面及原生桥契约测试
tests/android/Smoke.java                           独立 Android instrumentation
scripts/build.py                                  本地 APK 构建与签名
```

新增资产页模块时：在 `core.js` 的 `PAGE_OPTIONS.wealth` 注册显示开关，在 `app.js` 接入资产页渲染；将数据加入 `empty()` / `migrate()`。新增一级页面时，还需在导航和设置页分别加入页面入口与页面配置。原生层无需变更即可使用现有 JSON 状态存储。新增系统能力应添加白名单原生操作，不允许模块自由调用任意远程 URL。

## 构建与验证

构建无 Gradle、无 npm 运行时依赖。使用官方 Android SDK platform 35、build-tools 35，及现有 JDK。脚本支持通过 `JAVA_HOME` 和 `ANDROID_SDK_ROOT` 指定路径。

```powershell
npm test
npm run preview
npm run test:browser
npm run build:android
python scripts/build-smoke.py
```

`test:browser` 需要先启动预览服务和本机 Chrome，独立无界面配置目录与用户浏览器分离。

个人构建签名保存在 `.tooling/personal-signing.jks`，后续升级使用相同签名即可覆盖安装。请保留这份文件；它不放进源码压缩包或 APK 中。最终 APK 的 SHA256 见 `dist/SHA256.txt`。

验证证据与当前限制见 [VERIFICATION.md](VERIFICATION.md)。
